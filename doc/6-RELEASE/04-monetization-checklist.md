# Monetization Checklist

## IAP / Subscription

- [ ] Product IDs defined.
- [ ] Free vs paid entitlements documented.
- [ ] Restore purchase flow.
- [ ] Paywall copy reviewed.
- [ ] Cancellation/management link if required.

## Ads

- [ ] Ad placements documented.
- [ ] Frequency cap.
- [ ] Consent/ATT if needed.
- [ ] No misleading reward/close UI.

## Paid App

- [ ] Value proposition clear.
- [ ] No hidden required backend cost without plan.
