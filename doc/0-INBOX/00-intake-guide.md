# Intake Guide

Codex dùng file này để phỏng vấn user theo từng bước nhỏ.

## Nguyên Tắc Hỏi

- Mỗi lượt chỉ hỏi 5-10 câu.
- Ưu tiên câu hỏi chọn đáp án.
- Cho phép user trả lời nhanh: `1:A`, `2:A,C`, `3:khác: ...`.
- Sau mỗi gate, Codex tóm tắt và xin xác nhận.
- Thông tin thiếu nhưng chưa blocker thì ghi vào `04-open-questions.md`.
