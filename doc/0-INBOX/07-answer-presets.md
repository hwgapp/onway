# Answer Presets

Preset giúp trả lời intake nhanh. Codex có thể đề xuất preset rồi user xác nhận/sửa.

## Utility Local-First

```text
Archetype: Utility
Backend: No
Admin/CMS: No
Monetization: Paid app hoặc IAP
Compliance: Basic privacy
Delivery: Mobile app + App Store checklist
```

## Learning Content App

```text
Archetype: Learning/content
Backend: Optional CMS
Admin/CMS: Nếu nội dung cập nhật thường xuyên
Monetization: Subscription/IAP
Compliance: Kids/privacy nếu phục vụ trẻ em
Delivery: Content model + lesson/player flow + store readiness
```

## AI Tool App

```text
Archetype: AI tool
Backend: Required for API key/quota
Admin/CMS: Optional prompt/config
Monetization: Subscription/IAP
Compliance: AI safety, privacy, data retention
Delivery: AI gateway + quota + prompt governance
```

## Game App

```text
Archetype: Game
Backend: Optional
Admin/CMS: Optional level/content pipeline
Monetization: Ads/IAP/subscription tùy game
Compliance: Ads, privacy, kids rating nếu trẻ em
Delivery: Core loop + level/content + economy + release checklist
```
