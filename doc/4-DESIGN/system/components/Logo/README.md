Official wordmark. `variant="light"` (On `red-500`, Way `ink-800`) for light backgrounds; `variant="dark"` (all white) for a red or charcoal background; `variant="white"` and `variant="ink"` are the standalone white and charcoal-monochrome files (print, invoices).

- Never redraw, recolor, rotate or add effects to the mark.
- Keep clear space equal to the height of the "O" around it; minimum height 20px.
