Trip/order status at the top of a `Sheet` (S-003, S-004, S-007, S-008, S-013, S-014).

- One per screen. `headline` is written from the user's point of view ("Anh Minh đang đến điểm đón"), `heading-sm`.
- `issue` / `disputed` / `cancelled` turn the current step red.
- Updates in real time; announce changes with `aria-live="polite"`.
