Lucide icon, 2px stroke, inherits `currentColor`. This bundle ships a small demo subset (`home`, `search`, `bell`, `car`, `check`, `close`, `plus`, `filter`, `wifiOff`) as a stand-in — production pulls the full Lucide set at `https://unpkg.com/lucide-static@0.544.0/icons/<name>.svg`.

- Sizes: 16 / 20 / 24px.
- An icon-only control always pairs with `IconButton`'s required label — never ship a bare icon as a tap target.
