Stops, status history, or admin audit log (S-004, S-008, S-013, S-014, S-018, S-019, S-021) — pass `actor` per item for the Audit Timeline variant (CMP-052).

- States: `done` (filled dot), `current` (red dot with halo), `pending` (hollow), `failed` (red square — never color alone).
- Audit rows always show actor + time and are never editable.
